# Благотворительный лендинг Парка «Сказка»

Статический адаптивный лендинг социальной программы «Подари ребёнку радость».

## Локальный просмотр

Откройте `index.html` напрямую или запустите любой статический HTTP-сервер из этой папки.

## Структура

- `index.html` — контент и семантическая структура страницы.
- `styles.css` — визуальная система, адаптив, доступные состояния и motion.
- `script.js` — мобильное меню, раскрытие правил и scroll-reveal.
- `assets/` — официальный логотип и оптимизированные фотографии Парка «Сказка» в WebP/JPG.
