# Благотворительный лендинг Парка «Сказка»

Адаптивный лендинг социальной программы «Подари ребёнку радость» с серверной отправкой заявок в Битрикс24.

Публичная версия: https://parkskazka.ru/charity/

## Локальный просмотр

Откройте `index.html` напрямую или запустите любой статический HTTP-сервер из этой папки. Отправка формы работает только на основном сервере с PHP и закрытой конфигурацией вебхука.

## Структура

- `index.html` — контент и семантическая структура страницы.
- `styles.css` — визуальная система, адаптив, доступные состояния и motion.
- `script.js` — мобильное меню, анимации, модальная форма и отправка данных на same-origin endpoint.
- `api/lead.php` — серверная валидация и передача заявки в Битрикс24; секретов в файле нет.
- `assets/` — официальный логотип и оптимизированные фотографии Парка «Сказка» в WebP/JPG.

## Интеграция с Битрикс24

Вебхук хранится на сервере вне web root в `/etc/parkskazka/charity-bitrix.env` и доступен только `root` и группе веб-сервера. Не добавляйте этот файл или полный URL вебхука в Git.

Endpoint формы: `/charity/api/lead.php`. Email передаётся только при заполнении; обязательные поля повторно проверяются на сервере. Endpoint проверяет источник запроса, honeypot и частоту отправок.
